# Second System Configuration Editor
Unleash the full potential of Second System with this easy-to-use settings app.
## Features
* Configuring the default Second System profile without touching the registry editor;
* A list of all programs set to run with Second System;
* Ability to change individual profile settings, as well as editing DLL redirection tables;
* Creating, importing and exporting custom profiles.
## System requirements
* .NET Framework 4.0;
* Windows Vista or later (tested on Windows 7);
* Second System must be already installed on your computer. Get Second System here:  
  https://www.patreon.com/c/win32/posts
